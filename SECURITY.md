# Security

Found a security problem in an Open Logix repo? Please report it privately,
not as a public issue, so it can be fixed before it's known:

1. Open the repo where the problem is, on GitHub.
2. Choose its **Security** tab, then **Report a vulnerability**.

Every Open Logix repo takes private reports this way. Only the people who
maintain the repo see the report; we discuss the fix with you there, and
publish an advisory when the fix is out.

For anything else, problems and ideas go to the issues of
[Logix IDE](https://github.com/openlogix/logix-ide/issues/new/choose) or
[Logix Engine](https://github.com/openlogix/logix-engine/issues/new/choose).
